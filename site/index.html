24/7 TV playout,

NoAr plays daily playlists or folders without interruption, puts breaks, lives and graphics over the running programme at their time, and publishes an XMLTV guide with artwork for IPTV players.

Everything a channel needs to stay on air

One server, one browser tab: the Player, the playlists, the Scheduler, graphics, storage and the report, for one channel or many.

Output that keeps going

HLS with adaptive renditions, SRT, RTMP or UDP streams, NDI and DeckLink SDI/HDMI. A destination that is down never stops the channel: NoAr reconnects by itself and says why.

Playlists and Scheduler

Build each day in the Playlist page, or play a folder. The Scheduler places a break, a clip or a live over whatever is on air, waiting for the clip or cutting in, once or on chosen weekdays.

Scheduled lives

NoAr pulls SRT, RTMP, RTSP, HLS or UDP streams from an ingest server such as MediaMTX and switches between files and lives through GStreamer, waiting for a lost signal.

Graphics and Composer

Design lower thirds, logos, clocks, tickers and L-shapes as layers with animations, fonts and fields. Put them on air from On air, the Scheduler, cues inside a video or a Stream Deck.

Live data in graphics

CSV, public Google Sheets, RSS/Atom and HTTP JSON fill template fields such as prices, scores and headlines, refreshed in place and keeping the last good values.

SCTE-35 ad breaks

Runs of commercials and breaks marked by hand, by API or inside a video are signalled in the SRT or UDP output for FAST platforms and ad servers, announced ahead.

XMLTV guide and report

A guide built from the playlists and a Kodi-style .nfo per programme, with posters, episode images and credits; and a report of what really aired, as PDF or spreadsheet.

External control

Keys and ready-to-copy commands for encoders, vMix, OBS, Stream Deck and scripts: extend or end a live, put graphics on and off, mark ad breaks.

Also: multiple channels, users with roles, a REST API, alerts by e-mail and ntfy, recording, loudness normalization, WebVTT subtitles, and updates from the browser.

Install in a few minutes

NoAr runs in Docker. You only need Docker with the Compose plugin on a Linux server. 

$ git clone https://github.com/LuizStSantos/NoAr.git
$ cd NoAr
$ docker compose pull
$ docker compose up -d --no-build

  1. Get the published image

    The commands download ghcr.io/luizstsantos/noar:latest, the newest release, instead of compiling on the server.

  2. Open the setup page

    Go to http://<server>:8787, create the admin user and keep the suggested folders under /data.

  3. Go on air

    Upload media in Storage, build a playlist and start the playout. Updates come from Settings › Updates.
