# Graphics font fixture

`graphics.ttf` is a subset of DejaVu Serif, renamed `NoArReviewSerif`, containing
U+0020–U+00FF. Its source is the distribution's DejaVu Serif 2.37. The accompanying
`LICENSE.txt` preserves the distribution copyright/license notice. The fixture
exists to verify that an uploaded family absent from the system font database
is loaded from its exact bytes in the browser and server. It is test artwork,
not a default template asset or a recommendation for production typography.
