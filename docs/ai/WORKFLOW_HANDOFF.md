# NoAr development handoff template

Use this compact format between the main Claude session, the Orchestrator, reviewers and the Documentation Guardian. Do not dump raw code, whole transcripts or logs.

- **Request / revision / base:**
- **Changed paths / relevant module:**
- **Owners / helpers actually used:**
- **What changed or was investigated:**
- **Verified evidence:** paths:lines, commands with outcomes, browser/runtime proofs
- **Tests not run or unavailable:**
- **Council vote:** only when an audit was requested, with five real ballots
- **Documentation impact:** UPDATED / NO_UPDATE_REQUIRED / FOLLOW_UP, target docs and references
- **Map refresh:** done / not needed / pending
- **Production / security / migration risk:**
- **Final gate:** NOT_READY / NEEDS_TESTING / ADVISORY_APPROVAL / NOT_APPLICABLE
- **Next action / required approval:**

The Guardian operates on **task handoffs**, not continuous access to hidden thoughts or other agents' private conversations.
