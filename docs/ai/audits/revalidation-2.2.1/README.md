# Historical audit revalidation — NoAr 2.2.1

Source baseline: `d4a1a0a8a41f39b90de23844910998431fd42510` (2026-11-05).
All 66 historical findings are accounted for below. This is a single-reviewer revalidation, not a new five-reviewer audit. Original reports, finding IDs and ballots are preserved; their BLOCKED/NOT_READY verdicts apply to their historical commits.

## Status meaning

- **FIX_PRESENT**: the cited defect has a corresponding correction in current source. Runtime closure requires separate evidence.
- **OPEN_STATIC**: the current source still contains the described condition; original severity is historical, not independently re-scored.
- **PARTIAL**: some aspects changed or a limitation remains; do not mark the entire finding closed.
- **OBSOLETE**: the cited implementation or supported feature was replaced/removed; replacement behavior is not automatically verified.
- **DISMISSED**: the original audit dismissed the claim and current source supports that decision.
- **NEEDS_REVALIDATION**: current runtime/hardware/legacy fixtures or additional analysis are required; explicitly unresolved.

## Verification ledger

See [evidence.md](evidence.md) for exact commands, environment, results and limits. Runtime is NOT_RUN for each finding unless evidence.md explicitly maps a passing test to it. No broadcast-readiness approval is issued. Council: **NOT_RUN**. Overall: **NEEDS_TESTING**.

## Current priorities

1. Review proxy trust: private/link-local peers are all trusted to supply forwarding headers (backend F-002).
2. Preserve operator context: media response ordering, fabricated channel fallback, overlapping alerts and route-leave protection (frontend F-008/F-011/F-012/F-014).
3. Cancel sibling chunk uploads on failure and handle photo refresh/JSON errors (frontend F-009/F-024).
4. Decide queue limits, update interruption policy and SCTE-35 resynchronization behavior (backend F-008/F-016/F-032).
5. Exercise GPU encoders, old-schema upgrades, repeated DST hours and decoded output continuity before operational sign-off.
