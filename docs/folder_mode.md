**Folder mode**
================

Instead of daily playlists, NoAr can play the videos of the storage folder one
after another. No playlist is needed, and files added to or removed from the
folder are picked up while it plays.

Choose **Folder** as the mode in **Settings › Playlist and storage**. The
same page sets which file extensions count as videos, and **Shuffle**: on, the
videos play in random order; off, in name order.

## Trimmed videos

Each video plays the part saved as its [trim](trim.md) in Storage; videos
without one play whole.
