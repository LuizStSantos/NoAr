# Graphics review gallery

Captured from the running disposable backend and database, in pt-BR. Desktop
screenshots are at most 1440 px wide; phone screenshots use 390 px. Composer
and Preview illustrate saved layers. Program and the HLS frames show actual
playout output from a synthetic gray video with audio; gray is the test source,
not a missing picture. Browser decoding and advancing playback time were checked.

[Download the complete PDF](review-gallery.pdf). It contains every image below,
with one image per page and its original aspect ratio. Zoom to inspect details.

Fresh installations use a 42×42 px stock logo with 12 px top/right margins.
Existing authored models are preserved; the Composer restore action is explicit,
undoable and requires Save. Player is read-only; operate models from Graphics.
The API/XMLTV pages are included for navigation context.

Validation: 686 Rust tests passed, 14 ignored; 26 browser tests passed;
Vue types, full ESLint, changed-file Prettier, production build and QA TypeScript
passed. HLS samples, health, source hashes and limitations are in
[the machine-readable evidence](review-evidence.json); the capture-time
[channel log](review-channel.log) contains no errors.

This review does not repeat the earlier full 2.2.1 parity run. A real LAN HTTP
origin was not reachable; the missing UUID browser API was simulated on loopback.
Clock and version 2.5 rundowns remain outside this delivery.
